# Repository Structure

This repository contains the implementation of the **dynamic 1D separator model (Model 2)** .
The code is modularly structured, separating input data, simulation scripts, results, and postprocessing tools.  
Below is an overview of the main components and their functions.

---

## `results/` and `results_csv/`

These folders contain the **simulation results** generated by the different test and wrapper scripts.

### `results/`
Contains **plots and figures** (`.png`, `.svg`, `.eps`) generated during model testing or postprocessing.  
These visualize variables such as holdup, flow rates, droplet distributions, and grid convergence behavior.  
It also includes log files and individual CSV files with results from single test runs.

### `results_csv/`
Contains **aggregated numerical outputs** from parallel or batch simulations.  
Each file corresponds to a specific type of study or evaluation, such as:

- `simulation_results_parallel_evaluation.csv`: general model evaluation results  
- `simulation_results_parallel_evaluation_sozh.csv`: flooding analysis results  
- `simulation_results_parallel_evaluation_detail*.csv`: detailed run outputs  
- `simulation_results_parallel_N_s.csv`, `simulation_results_parallel_N_d.csv`: grid independence tests  
- `simulation_results_sensitivity_lambda.csv`, `simulation_results_te_*.csv`: sensitivity or validation datasets  

---

## 📂 `settings/`

This folder contains all **input files, constants, and functions** necessary to initialize and execute simulations of the model.

- **`data_main.xlsx`**  
  File containing the full dataset used in the Master’s Thesis of Iván Guzmán. It compiles experimental and literature data from:
  - **Ye’s dissertation (TU Berlin)**  
  - **AVT Laboratory (RWTH Aachen)**  

  These data include hydrodynamic and physical properties used for model validation.

- **`df_te_dpz.csv`** and **`df_te_lam.csv`**  
  Testing datasets used for the **validation of this model (M2)**, as reported in the Master’s Thesis of Iván Guzmán.

- **Other files**  
  Define the **input parameters, constants, and auxiliary functions** required to run the dynamic 1D separator model, such as:
  - `constants.py`: physical constants and dimensionless numbers  
  - `main_script_fun.py`: routines for initializing and executing simulations  
  - `plot_fun.py`: plotting and visualization utilities

---

## 🧩 Main Python Files

| File | Description |
|------|--------------|
| **`separator_model.py`** | Core file containing all model methods and properties. Implements the dynamic 1D separator model equations, initialization routines, and solver logic. |
| **`postprocessing.py`** | Postprocessing script for evaluating multiple simulations with different operating points. Imports results from CSV files (e.g., from `results_csv/`) and generates contour plots and other performance visualizations. |
| **`test_script_parallel_evaluation.py`** | Runs **parallel simulations** of the model for a range of operating conditions. Takes its input parameters from the files contained in the `settings/` folder. |
| **`test_script_parallel_grid_independence.py`** | Runs **parallel simulations** as part of a grid independence analysis to determine the optimal numerical parameters **Nₛ** and **N_d**. |
| **`test_script_parallel_sensitivity_analysis.py`** | Runs **parallel simulations** for sensitivity analysis of manually defined inputs (currently total volumetric flow rate `dV_ges` and Sauter mean diameter `phi_0`). |
| **`test_script_searchflooding_sozh.py`** | Runs tests to determine the **flooding point**, i.e., the total volumetric flow rate at which flooding occurs. |
| **`test_script.py`** | Basic script for testing and verifying the correct functionality of the model. |
| **`wrapper_calc_flooding_sozh.py`** | Example script demonstrating how **parallel simulations** can be executed for flooding analysis using the Sozh parameter set. |
